# Relatorio TikTok

Static public website for **Relatorio TikTok**, a TikTok Content Performance Analytics project.

## Pages

- [Home](https://caio-angelis.github.io/relatorio-tiktok/)
- [Privacy Policy](https://caio-angelis.github.io/relatorio-tiktok/privacy.html)
- [Terms of Service](https://caio-angelis.github.io/relatorio-tiktok/terms.html)

## Local preview

Open `index.html` directly in a browser, or serve the folder with any simple static file server.

## Before TikTok app review

Replace the `[CONTACT_EMAIL]` placeholder in `terms.html` and `privacy.html` with a real contact email address before submitting the application for review.
